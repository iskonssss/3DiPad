# NFC Spinner Keychain — reference files

Print-in-place fidget spinner keychain used in corporate workshops.
The centre disc rotates freely after printing. An NFC chip sits in a
floating 22 x 12 x 0.6 mm cavity inside.

Folders:
- `blank/`        — spinner with no design (STL, G-code, 3mf)
- `with design/`  — same spinner with a two-colour drawing (STL, G-code, 3mf)

Known settings (from the owner):
- Bridge speed 20 mm/s (slicer default was 50)
- Colour depth: 2 layers, top and bottom
- Faces are flat; the design is inlaid, not raised
