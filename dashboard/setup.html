🔌 Printer Setup

← Back to the booth

Get these three from the printer's own screen, then press Save and Test.
• IP address and Access Code: Settings → Network, with LAN Mode ON
• DEVELOPER MODE must be ON too (same Network screen, or Bambu Handy). Without it the printer answers status, obeys the light and accepts uploads — and silently refuses every print command, so files arrive on the SD card and nothing ever starts. Restart the printer after turning it on. Test below will say so if it is off.
• Serial: Settings → Device
The access code changes whenever LAN Mode is switched off and on again, so re-read it if a printer stops answering.
